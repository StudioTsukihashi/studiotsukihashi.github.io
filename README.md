# Studio Tsukihashi – Website Version 1.0

## Enthaltene Dateien

- `index.html` – Startseite
- `styles.css` – gesamtes Design
- `script.js` – mobiles Menü und automatische Jahreszahl
- `impressum.html` – Platzhalter
- `datenschutz.html` – Platzhalter
- `assets/` – hier später Logo und Bilder ablegen

## Upload zu GitHub

1. Im Repository `StudioTsukihashi.github.io` alle vorhandenen Dateien öffnen.
2. `Add file` → `Upload files`.
3. Die Dateien aus diesem Paket hochladen.
4. `Commit changes` bestätigen.
5. Nach kurzer Zeit `https://studiotsukihashi.github.io` neu laden.

## Noch anzupassen

- Platzhalter-E-Mail in `index.html`
- bürgerlicher Name, Anschrift und E-Mail im Impressum
- Datenschutzerklärung rechtlich prüfen
- finalen Autorinnennamen einsetzen
- originales Studio-Logo später in `assets/` ergänzen

## Logo später einsetzen

Lege das Logo zum Beispiel als `assets/studio-tsukihashi-logo.png` ab.
Danach kann der Platzhalter im Kopfbereich durch ein `<img>` ersetzt werden.
